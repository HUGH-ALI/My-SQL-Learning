一、PL/SQL 内置6大类数据类型
1. 数字类型 NUMBER(p,s)
- p：精度，全部有效数字总位数（1~38）
- s：刻度，小数点后面的位数
例： NUMBER(8,2)  → 最多8位数字，小数占2位，范围： -999999.99 ~ 999999.99 
 
2. 字符类型 CHAR / VARCHAR2
和表里面的CHAR、VARCHAR2逻辑一样，PL/SQL里这俩最多存4000字节。

- CHAR：定长，不足长度自动补空格
- VARCHAR2：变长，存多少占多少空间
 
3. 日期类型 DATE / TIMESTAMP
 
- DATE：存 年、月、日、时、分、秒，没有毫秒
- TIMESTAMP：带毫秒的时间
 
4. 布尔类型 BOOLEAN
❗只能在PL/SQL里面用，数据库表的列不能用BOOLEAN！
取值只有三个： TRUE 、 FALSE 、 NULL 
5. LOB大对象类型
 LOB类型变量最大可以存4GB
- BLOB：存放二进制数据（图片、文件）
- CLOB：存放长文本数据
- NCLOB：支持存放中文的长文本数据
- BFILE：存放一个指针，指向服务器磁盘上的外部文件，数据不在数据库里

 6. 记录类型 RECORD（复合类型）
相当于自己组装一个“自定义盒子”，里面包含好几个不同字段。
语法模板：
plsql
  
TYPE 类型名 IS RECORD(
  字段1 数据类型,
  字段2 数据类型
);
eg:
 TYPE record_type IS RECORD(
fieldl datatype1 [NOT NULL][DEFAULT|:=expr1],
field2 datatype2[NOT NULL][DEFAULT|:=expr2],
fieldn datatypen [NOT NULL][DEFAULT|:=exprn]);
 
课本【例9-3】拆解：
DECLARE
  -- 定义记录类型：包含员工编号、姓名、工资
  TYPE t_emp IS RECORD( 
    empno NUMBER(4), 
    fname CHAR(10), 
    sal NUMBER(8,2)
  );
  v_emp t_emp; -- 用刚才的记录类型，定义变量v_emp
BEGIN
  SELECT employee_id,first_name,salary INTO v_emp 
  FROM employees WHERE employee_id=109;
  -- 取记录里面成员：变量名.成员名
  DBMS_OUTPUT.PUT_LINE(v_emp.fname||' '||v_emp.sal);
END;
 
二、两个特殊属性： %TYPE  和  %ROWTYPE （超级高频）
 
  %TYPE 
作用：当要定义的变量类型 和 某个变量数据类型或者表中某一列的类型一模一样（不知道该变量或列的数据类型），可以用%TYPE来实现。
好处：以后表字段改类型了，变量自动跟着变，不用手动改代码
 
plsql
  
v_sal employees.salary%TYPE;
-- 含义：v_sal 的类型 = employees表的salary列的数据类型
 
 
  %ROWTYPE 
 如果要定义一个与数据库中某个表结构一致的记录类型的变量，可以使用%ROWTYP来实现。
好处：变量和整张表一行的结构完全一样，自动包含表所有列
语法：
 变量名 表名%ROWTYPE;
复制这张表一行里面每一列的数据类型
plsql
  
v_emp employees%ROWTYPE;
-- v_emp 里面自动拥有 employees 全部列：employee_id,first_name,salary...
-- 取值：v_emp.employee_id、v_emp.salary
 
 
课本【例9-4】查询109号员工的工资以及140号员工的员工名与工资，并输出。
 DECLARE
  v_sal employees.salary%TYPE;
  v_emp employees%ROWTYPE;
BEGIN
  SELECT salary INTO v_sal FROM employees WHERE employee_id=109;
  SELECT * INTO v_emp FROM employees WHERE employee_id=140;
  DBMS_OUTPUT.PUT_LINE(v_sal);
  DBMS_OUTPUT.PUT_LINE(v_emp.first_name||v_emp.salary);
END;
注意：哪怕原列有NOT NULL约束， %TYPE  /  %ROWTYPE  拿到的变量不带NOT NULL限制
 
重点：他俩只能复制表结构，但表的所有约束不能复刻。
 
 
三、变量和常量定义
语法模板：
 
plsql
  
变量名 [CONSTANT] 数据类型 [NOT NULL] [DEFAULT | := 初始值];

说明：
每行只能定义一个变量。
如果加上关键字CONSTANT，则表示所定义的是一个常量，必须为它赋初值。且后面代码不能修改
如果定义变量时使用了 NOT NULL关键字，则必须为变量赋初值。
使用DEFAULT或“：=”运算符为变量初始化。

课本【例9-5】
plsql
  
DECLARE
  v1 NUMBER(4);                    -- 普通变量，默认是NULL
  v2 NUMBER(4) NOT NULL :=10;       -- 非空变量，必须立刻赋值
  v3 CONSTANT NUMBER(4) DEFAULT 100;-- 常量，固定100，不能改
BEGIN
  IF v1 IS NULL THEN
    DBMS_OUTPUT.PUT_LINE('V1 IS NULL!');
  END IF;
  DBMS_OUTPUT.PUT_LINE(v2||' '||v3);
END;
v2拼接' '里的空格再拼接v3
 ' :字符串起止符号!
 
四、变量作用域  
变量的作用域是指变量的有效作用范围，从变量声明开始，直到块结束。如果PL/SQL块
相互嵌套，则在内部块中声明的变量是局部的，只能在内部块中引用，而在外部块中声明的变量是全局的，既可以在外部块中引用，也可以在内部块中引用。如果内部块与外部块中定义了同名变量，则在内部块中引用外部块的全局变量时需要使用外部块名进行标识。
PL/SQL块可以嵌套：外层块、内层块
 
- 内层块声明的变量：局部变量，只能在内层块里面用
- 外层块声明的变量：外层作用域，内层可以直接访问
- 如果内层、外层变量同名：内层优先用自己的；想访问外层，要给外层块起标签  <<OUTER>> ，用  OUTER.变量名 
 【例9-6】
<<OUTER>>  -- 给外层块打标签
DECLARE
  v_fname CHAR(14);
  v_outer NUMBER(5);
BEGIN
  v_outer :=10;
  DECLARE -- 内层块开始
    v_fname CHAR(20);
    v_inner DATE;
  BEGIN
    v_inner:=sysdate;
    v_fname:= 'INNER V_ENAME';
    OUTER.v_fname:= 'OUTER V_ENAME'; -- 访问外层同名变量
  END; --内层结束
  DBMS_OUTPUT.PUT_LINE(v_fname);
END;

最终打印的是外层全局变量vfname，即OUTER V_ENAME
内层块结束，内层的局部变量直接消失!!!
 如果删掉  OUTER. ，写成  v_fname:= 'OUTER V_ENAME' ，那只会修改内层变量，外层v_fname依旧是NULL，打印出来是空。
 
 
9.5 PL/SQL里面的SQL语句
 
重点：PL/SQL 只支持：SELECT、DML(INSERT/UPDATE/DELETE)、事务语句(COMMIT、ROLLBACK)；不支持直接写CREATE TABLE这类DDL（建表）
 
1. SELECT ... INTO 【重中之重】
 
语法：
 
plsql
  
SELECT 列1,列2... INTO 变量1,变量2... FROM 表 WHERE 条件;
 
 
规则  
 
1. 只能查到1行！
- 查不到数据 → 抛出  NO_DATA_FOUND 
- 查出多于1行 → 抛出  TOO_MANY_ROWS 
2. INTO后面变量数量、顺序、类型，要和SELECT后面的列一一对应
3. 也可以直接INTO 一个 %ROWTYPE 记录变量
 
【例9-7】
 
plsql
  
DECLARE
  v_emp employees%ROWTYPE;
  v_lname employees.last_name%TYPE;
  v_sal employees.salary%TYPE;
BEGIN
  SELECT * INTO v_emp FROM employees WHERE last_name='Bell';
  DBMS_OUTPUT.PUT_LINE(v_emp.employee_id||' '||v_emp.salary);

  SELECT last_name,salary INTO v_lname,v_sal 
  FROM employees WHERE employee_id=109;
  DBMS_OUTPUT.PUT_LINE(v_lname||' '||v_sal);
END;

 
 
2. DML语句（INSERT / UPDATE / DELETE）
 
和普通SQL写法差不多，可以直接在PL/SQL里面用变量
 
plsql
  
DECLARE
  v_id NUMBER := 1001;
BEGIN
  INSERT INTO test(id) VALUES(v_id); -- 把变量放进DML
  COMMIT; -- 提交事务
END;
