三大类：选择结构（IF、CASE）、循环结构（LOOP、WHILE、FOR）、跳转结构（GOTO）

&#x20;

一、选择结构：IF 语句

语法  

IF 条件1 THEN  语句1;  

ELSIF 条件2 THEN  语句2;  

ELSE  语句3;  

END IF;

⚠️ 注意拼写：是 ELSIF（少一个E），最后  END IF  分开写！  

&#x20;

课本【例9-9】  

需求：输入员工编号，根据部门涨工资  

\- 10号部门：+100  

\- 20号部门：+140  

\- 30号部门：+200  

\- 其他部门：+300  

&#x20;DECLARE

&#x20; v\_deptno employees.department\_id%TYPE;

&#x20; v\_increment NUMBER(4);

&#x20; v\_empno employees.employee\_id%TYPE;

BEGIN

&#x20; v\_empno:=\&x; -- \&x 是替换变量，运行时输入员工号

&#x20; SELECT department\_id INTO v\_deptno FROM employees WHERE employee\_id=v\_empno;

&#x20; IF v\_deptno=10 THEN

&#x20;   v\_increment:=100;

&#x20; ELSIF v\_deptno=20 THEN

&#x20;   v\_increment:=140;

&#x20; ELSIF v\_deptno=30 THEN

&#x20;   v\_increment:=200;

&#x20; ELSE

&#x20;   v\_increment:=300;

&#x20; END IF;

&#x20; UPDATE employees SET salary=salary+v\_increment WHERE employee\_id=v\_empno;

END;

解释:

1\. DECLARE 块：定义变量  

v\_deptno employees.department\_id%TYPE;  

\-  %TYPE ：引用型定义，变量类型和  employees  表的  department\_id  字段一模一样  

\- 好处：表字段改类型，变量自动适配，不用手动改代码  

\-  v\_deptno ：用来存查到的部门编号  

&#x20;

v\_increment NUMBER(4);  

&#x20;- 数字类型，最多4位，存放涨薪金额

&#x20;

v\_empno employees.employee\_id%TYPE;  

&#x20;- 存放输入的员工编号，类型和employee\_id保持一致  

&#x20;

2\. BEGIN ... END 是程序主体  

v\_empno:=\&x;  

&#x20; \&x ：替换变量（ substitution variable）  

\- 运行脚本的时候，弹窗让你输入一个值，赋值给v\_empno  

\- 注意： \&x  是SQL\*Plus/PLSQL Developer工具的语法，不是PL/SQL语言本身  

\- 运行时提示： Enter value for x: ，你输入员工号，比如 101  

&#x20;

⚠️ 坑点：如果输入的员工号不存在，下面SELECT会直接报错：no data found，程序终止（这里代码没有异常捕获）  

&#x20;

SELECT department\_id INTO v\_deptno   

FROM employees WHERE   employee\_id=v\_empno;  

&#x20;

\-  SELECT ... INTO ：PL/SQL专用语法，单行查询，把查询结果放到变量  

\- 根据员工编号，查出这个员工的部门ID，存入v\_deptno  

\- 硬性要求：只能查到1行；0行 / 多行都会抛异常  

&#x20;

3\. IF-ELSIF 分支判断（重点！Oracle PL/SQL 是 ELSIF，不是 ELSEIF）   

IF v\_deptno=10 THEN  

&#x20;   v\_increment:=100;  

ELSIF v\_deptno=20 THEN  

&#x20;   v\_increment:=140;  

ELSIF v\_deptno=30 THEN  

&#x20;   v\_increment:=200;  

ELSE  

&#x20;   v\_increment:=300;  

END IF;  

&#x20;

逻辑：  

\- 部门10 → 涨薪100  

\- 部门20 → 涨薪140  

\- 部门30 → 涨薪200  

\- 其余所有部门 → 涨薪300  

\-  :=  是PL/SQL赋值符号，不是等号，等号只用在判断  =   

&#x20;

4\. UPDATE 更新语句  

plsql

&#x20; 

UPDATE employees SET   salary=salary+v\_increment WHERE   employee\_id=v\_empno;  

\- 找到这个员工，在原有工资基础上，加上前面判断好的涨薪数额  

\- 只更新这一个员工  

&#x20;✅ 逻辑：从上往下依次判断，满足一个就执行，后面不再判断  

&#x20;

重点考点：NULL 的坑  

&#x20;

PL/SQL 的逻辑值有三种： TRUE / FALSE / NULL   

&#x20;NULL 参与比较，结果还是NULL，不进入IF，也不进ELSE，会直接跳过。  

所以规范写法要先判断  IS NULL ：  

&#x20;IF v\_num1 IS NULL OR v\_num2 IS NULL   THEN  

&#x20; v\_result:='UNKNOWN';  

ELSIF v\_num1 < v\_num2 THEN  

&#x20; v\_result:='YES';  

ELSE  

&#x20; v\_result:='NO';  

END IF;

三、循环结构（3种）  

1\. 简单循环 LOOP（无条件循环，在内部判断退出）  

语法：  

&#x20;LOOP  

&#x20; 循环体;  

&#x20; EXIT WHEN 退出条件; -- 满足条件就跳出循环  

END LOOP;    

❗硬性要求：必须写EXIT，不然死循环！  

&#x20;

【例9-11】求1\~100偶数和  

&#x20;DECLARE  

&#x20; v\_counter BINARY\_INTEGER :=1;  

&#x20; v\_sum NUMBER :=0;  

BEGIN  

&#x20; LOOP  

&#x20;   IF mod(v\_counter,2)=0 THEN -- mod取余，余0=偶数  

&#x20;     v\_sum:=v\_sum+v\_counter;  

&#x20;   END IF;  

&#x20;   v\_counter := v\_counter +1;  

&#x20;   EXIT WHEN v\_counter>100; -- 大于100退出  

&#x20; END LOOP;  

&#x20; DBMS\_OUTPUT.PUT\_LINE(v\_sum);  

END;  



declare vcounter=1,第一次，%2不为0，vcounter+1变为 vcounter=2,第二次，vcounter%2为0，sum=sum+vcounter即

0=0+2

&#x20;

2\. WHILE 循环：先判断，满足条件才进循环   

语法：  

WHILE 条件 LOOP  

&#x20; 循环体;  

END LOOP;  

&#x20;【例9-12】同样求1\~100偶数和   

DECLARE  

&#x20; v\_counter BINARY\_INTEGER :=1;  

&#x20; v\_sum NUMBER :=0;  

BEGIN  

&#x20; WHILE v\_counter <= 100 LOOP  

&#x20;   IF mod(v\_counter,2)=0 THEN  

&#x20;     v\_sum:=v\_sum+v\_counter;  

&#x20;   END IF;  

&#x20;   v\_counter := v\_counter +1;  

&#x20; END LOOP;  

&#x20; DBMS\_OUTPUT.PUT\_LINE(v\_sum);  

END;  



区别LOOP：WHILE是先判断再执行；LOOP是先执行再判断退出  

&#x20;

3\. FOR 循环（最省心，自动管理循环变量） 

语法：  

&#x20;FOR 变量 IN \[REVERSE] 下界..上界 LOOP

&#x20; 循环体;  

END LOOP;      

考点：  

&#x20;1. 循环变量不用DECLARE定义！系统自动创建（BINARY\_INTEGER）  

2\. 默认从小到大；加  REVERSE  从大到小倒着循环  

3\. 循环变量只能在LOOP里面使用，循环外面访问不到  

【例9-13】FOR求1\~100偶数和  

DECLARE  

&#x20; v\_sum NUMBER :=0;  

BEGIN  

&#x20; FOR v\_counter IN 1..100 LOOP  

&#x20;   IF mod(v\_counter,2)=0 THEN  

&#x20;     v\_sum:=v\_sum+v\_counter;

&#x20;   END IF;  

&#x20; END LOOP;  

&#x20; DBMS\_OUTPUT.PUT\_LINE(v\_sum);  

END;  



✅ 三种循环一句话区分

\- LOOP：先执行，内部EXIT退出  

\- WHILE：先判断，条件成立才跑  

\- FOR：固定次数，自动增减，不用手动改计数器  

&#x20; 

四、跳转结构：GOTO  

作用：跳到标记的位置  <<标签>>   

&#x20;DECLARE  

&#x20; v\_counter BINARY\_INTEGER :=1;  

BEGIN  

&#x20; <<LABEL>>  

&#x20; INSERT INTO temp\_table VALUES   (v\_counter, 'Loop index');  

&#x20; v\_counter := v\_counter +1;  

&#x20; IF v\_counter<=50 THEN  

&#x20;   GOTO LABEL; -- 跳回LABEL位置  

&#x20; END IF;  

END;  

&#x20;

&#x20;

GOTO 3条禁令     

1\. 块内可以跳；内层块可以跳到外层，外层不能跳到内层块  

2\. 不能从外面跳进IF内部、跳进循环内部、跳进子程序内部  

3\. 破坏结构化，开发尽量不用GOTO
