NUMBER 和 INT 区别
Oracle 没有真正独立的 int 类型，INT 只是 NUMBER(38) 的别名
1. NUMBER
语法： NUMBER(p,s) 
- p：精度，总位数（整数+小数），范围 1~38
- s：标度，小数点右边位数
①NUMBER        -- 不写p,s：可以存很大的数，整数、小数都能放
②NUMBER(5)     -- 只能存整数，最多5位，等价 NUMBER(5,0)
③NUMBER(6,2)   -- 一共6位，小数占2位，例：1234.56


CHAR
语法： CHAR(n) 
- n：字节长度，范围 1~2000
- 定长：不管你输入内容多长，它都占 n 个字节
- 输入内容短了 → 自动在右边补空格补齐长度
- 输入超过n → 报错
适合：长度固定的数据，比如学号、身份证、性别、编码

2. VARCHAR2
语法： VARCHAR2(n) 
- n：最大字节，1~4000（12c以后支持32767）
- 变长：存多少字符，就占多少空间，不补空格
适合：长短不固定的数据，姓名、地址、备注
