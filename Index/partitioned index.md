在Oracle数据库中，索引与表是相互独立的，索引是否分区与表是否分区没有直接关系
不分区的表可以创建分区索引或不分区索引，分区的表也可以创建分区索引或不分区的索引
在Oracle数据库中，分区索引分为本地分区索引和全局分区索引两种。  
我的理解：  
①全局分区索引就是先给整张表(可以是不分区表也可以是分区表)建立索引，假设索引从 1 开始 ，然后再给索引建立分区，我在1-100为一个分区索引，100-200为一个分区索引...也可以奇书索引作为一个索引分区偶数索引作为一个索引分区。  
举例子：给分区表建立分区索引  
表按【籍贯】分成浙江、贵州两个分区；  
全局索引按【年龄】分区：p1(＜80)，p2(≥80)。  
那么：  
浙江分区里年龄50、贵州分区里年龄60的数据，都会跑到索引的p1分区里；  
浙江分区年龄90、贵州分区年龄95的数据，都会跑到索引的p2分区里。  
👉 重点：  
全局索引的分区，是跨表分区的，一个索引分区里面，可以包含来自多个表分区的数据。  

②本地分区索引，前提表是分区表，然后给每个表分区创建一个索引，每个表的分区索引都是从1开始，并不是说前一个分区最后一个索引是100，下一个的开始索引是101，而是1。  

分区表建立的不分区索引是什么索引  
全局非分区索引  
（1)本地分区索引是指为分区表中的各个分区单独创建索引分区，各个索引分区之间是相互独立的，索引的分区与表的分区是一一对应的，如图6-2所示。为分区表创建了本地分区索引后，Oracle会自动对表的分区和索引的分区进行同步维护  
(2)全局分区索引是指先对整个表建立索引，然后再对索引进行分区。索引的分区之间不  
是相互独立的，索引分区与表分区之间也不是一一对应的。  

1. 所有不分区的索引，统一叫：全局非分区索引（不管表是分区表、还是普通表 ）  

2. 分区索引分两种：  
-①普通不分区表上的分区索引：只能是 全局分区索引（不能建LOCAL）  

- ②分区表上的分区索引：  
- 加 LOCAL → 本地分区索引  
- 加 GLOBAL PARTITION BY → 全局分区索引  
例子：  
LOCAL 本地分区索引：  
CREATE INDEX idx_stu_native ON student(native_place) LOCAL;  
特点：  
表有2个分区，索引自动生成2个索引分区  
- 索引分区 p_zj 👉 只存浙江分区的数据索引  
- 索引分区 p_gz 👉 只存贵州分区的数据索引  

GLOBAL PARTITION BY 全局分区索引：  

CREATE INDEX idx_stu_age ON student(sage)  
GLOBAL PARTITION BY RANGE(sage)  
(  
    PARTITION p1 VALUES LESS THAN (20),  
    PARTITION p2 VALUES LESS THAN (100)  
);  
特点：  
索引自己单独一套分区规则（按年龄），和表的籍贯分区无关  
- 索引分区p1（<20岁）：里面既有浙江的学生，也有贵州的学生  
- 索引分区p2（20~99岁）：同样混合两个表分区的数据  
👉 重点：索引分区跨表分区，数据混在一起  
👉 坑：如果删除/拆分表的分区，这个全局索引很容易失效，需要重建  

 


二，建立分区索引  
1)创建本地分区索引  
分区表创建后，可以对分区表创建本地分区索引。在指明分区方法时使用LOCAL关键字  
标识本地分区索引。  
【例6-39】在student_range 分区表的sname列上创建本地分区索引。  
SQL>CREATE INDEX student_range_local ON student_range (sname) LOCAL;  
 
2）全局分区索引  
与表分区方法类似，索引分区方法也包括范围分区、列表分区、散列分区和复合分区等。在指明分区方法时使用GLOBAL关键字标识全局分区索引。  
CREATE INDEX student_range_global   
ON student_range(sage)  
GLOBAL PARTITION BY RANGE(sage)  
(   PARTITION p1 VALUES LESS THAN (80) TABLESPACE ORCLTBS1,  
    PARTITION p2 VALUES LESS THAN (MAXVALUE) TABLESPACE ORCLTBS2  
);  
3) 全局非分区索引  
和普通表建索引写法一模一样：  
CREATE INDEX idx_stu ON student_range(sname);
