\*\*Oracle 登录数据库语句\*\*：



conn 用户/密码@服务器数据库名称



eg：



CONN human/her@HUMAN\\\\\\\_RESOURCE







\*\*Oracle执行外部脚本语句\*\*：



@脚本路径



eg:     @C:\\\\\\\\human\\\\\\\_popul.sql











\*\*MySQL 登录数据库语句\*\*：



mysql  -u用户  -p密码







示例1：在操作系统cmd终端（黑窗口）直接登录MySQL



mysql -u human -p her -h localhost -P 3306







解释：



\&#x20;-u human ：用户名human



\\-p her ：密码her（p后面不能空格）



\\-h localhost ：数据库在本机



\\-P 3306 ：端口号，默认3306，本机可省略















👉 \*\*未登录阶段\*\*，登录只能用操作系统命令：



\&#x20;mysql -u用户名 -p密码











\*\*已经登录\*\*了，在 mysql> 提示符里面



✅ 才可以执行



CONNECT user IDENTIFIED BY 'pwd';







CONNECT是客户端内部切换账号，必须先进到数据库交互界面（有mysql>提示符）才能用；



完全没登录的时候，只能在操作系统cmd用 mysql -u 登录。











示例2：登录进MySQL之后，执行外部脚本（source）







MySQL 执行外部脚本语句：



source 脚本路径



eg:   source C:/human\\\\\\\_popul.sql;







\\-- 1.用管理员sysdba登录数据库



CONNECT sys/tiger @HUMAN\\\_RESOURCE AS SYSDBA







AS：



\\- ✅ SYSDBA / SYSOPER：特权身份（登录身份）



只给 sys 用户使用，写在  CONNECT ... AS SYSDBA



CONNECT sys/tiger AS SYSDBA;    --最高权限：建用户、删表空间、启停库



CONNECT sys/tiger AS SYSOPER;   --权限更小：只能启停、备份，不能建用户



只有特权身份才可以用AS!











\\-- 2.创建human用户，密码human，默认表空间USERS



CREATE USER human IDENTIFIED BY human DEFAULT TABLESPACE USERS;



\\--3.给human授权：连接权限、资源权限、创建视图权限



GRANT CONNECT,RESOURCE,CREATE VIEW TO human;







用human连接数据库



CONNECT human/human @HUMAN\\\_RESOURCE







1\\.  CONNECT sys/tiger @HUMAN\\\_RESOURCE AS SYSDBA



用系统管理员 sys ，密码 tiger ，登录到 HUMAN\\\_RESOURCE 数据库，身份是 SYSDBA （只有管理员才能新建用户）







2\\.  CREATE USER human IDENTIFIED BY human DEFAULT TABLESPACE USERS;



创建用户名叫 human ，密码 human ；它的默认存储表空间是 USERS
